PHASE 1: PROJECT ANALYSIS
================================
Language:      JavaScript (Node.js)
Framework:     Express 4.18.2 pinned in package.json / 4.22.1 resolved in package-lock.json
Dependencies:  express, sqlite3 (^5.1.6 / 5.1.7 resolved), bcryptjs (^2.4.3 / 2.4.3 resolved), zod (^3.23.8 / 3.25.76 resolved) for schema validation, dotenv (^16.4.5 / 16.6.1 resolved) for config
Domain:        LMS (online course platform) with a purchase/checkout flow — entities are courses, enrollments, payments, users, audit_logs; routes are /api/checkout, /api/users/:id, /api/admin/financial-report. Note: the project folder is named "ecommerce-api-legacy" and was seeded from an e-commerce-flavored boilerplate, but the actual domain per routes/tables/code (and the boot log "Frankenstein LMS rodando...") is course sales/enrollment, not generic product/order e-commerce.
Architecture:  Layered / MVC — already refactored, not one of the three legacy problem shapes. src/ is split into config/, controllers/, middlewares/, models/, routes/, services/, utils/ (23 .js files total: config 2, controllers 3, middlewares 3, models 5, routes 4, services 3, utils 2, plus src/app.js as composition root). Verified no responsibility leaks: routes/*.js only parse via middleware and call a controller; controllers (checkoutController, userController, financialReportController) hold orchestration only; models/*.js are pure parameterized-query data access (one per table: users, courses, enrollments, payments, audit_logs); business rules (payment approval/card masking, password hashing, in-memory cache) live in services/; config/database.js is the single place that owns the sqlite3 driver, schema, and transactions. Git history confirms this: original code lived in a single God File (src/AppManager.js + src/utils.js, per README's "Análise Manual" section, 21 findings) and was restructured in commit "refactor: restructure ecommerce-api-legacy into MVC and fix security findings". No leftover flat-monolith or god-class files were found on disk.
Source files:  23 files analyzed (all .js under src/; full recursive project listing outside node_modules/.git/.refactor-arch/reports also includes package.json, package-lock.json, .env.example, api.http, README.md — no other source code files)
DB tables:     users, courses, enrollments, payments, audit_logs (SQLite, in-memory `:memory:` database, schema created via CREATE TABLE IF NOT EXISTS in src/config/database.js:initSchema, seeded via seedData())
